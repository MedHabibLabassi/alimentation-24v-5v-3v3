# Alimentation industrielle 24 V DC → 5 V / 3,3 V

Conception complète d'une alimentation basse tension pour cartes industrielles, réalisée sous KiCad.

## Spécification
- Entrée : 24 V nominal (18 à 32 V)
- Sorties : 5 V / 1 A et 3,3 V / 0,5 A
- Protections : inversion de polarité, surtension, court-circuit, surintensité
